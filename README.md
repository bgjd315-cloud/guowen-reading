# 國文閱讀理解判讀

會考國文（111–115 年）與學測國文（107–115 年）共 560 題的閱讀理解分析。每一題都依 PISA 閱讀歷程標上三項：

- **閱讀能力**：擷取與檢索（A1、A2）、統整與解釋（B1–B4）、省思與評鑑（C1、C2），以及語文知識（K）
- **陷阱類型**：最具誘答力的錯誤選項屬於哪一類（字面相符語意不同、過度推論、張冠李戴、以偏概全、常識干擾、關係倒置、形近義混）
- **判讀提示**：一句解題方向

本專案由 [huikao-analysis](https://github.com/bgjd315-cloud/huikao-analysis) 的國文部分複製而來。

## 頁面

| 路徑 | 內容 |
|---|---|
| `/` | 閱讀理解總覽：重點發現、能力分布、各能力答題方法、陷阱類型、會考到學測的銜接 |
| `/bank/` | 判讀題庫：依考試、年度、能力、陷阱篩選，可遮住答案與提示自我練習 |
| `/guowen/` | 會考國文命題分析與原題試題庫 |
| `/xuece/` | 學測國文命題分析與原題試題庫 |

## 資料

- `tools/reading_cls.py`：逐題判讀，每年一段文字，每題一筆「能力 陷阱 提示」，以「｜」分隔，順序與試卷題號相同
- `tools/reading_data.py`：把判讀與 `data/` 的題目、答案合併，供頁面使用
- `data/guowen/`、`data/xuece/`：各年度題目、答案與分類
- `assets/`：從官方試卷裁切的題目圖片

## 建置與檢查

```bash
python build.py
python tools/verify.py
```

`build.py` 會檢查每年的題數、分類數與判讀數是否一致；推送到 main 後由 GitHub Actions 自動發布到 GitHub Pages。

## 新增一年

1. 依 huikao-analysis 的 `docs/年度更新流程.md` 與本專案 `tools/xuece/` 的工具產生該年度的 `data/<考試>/<年度>.json` 與題目圖片
2. 在 `tools/reading_cls.py` 補上該年度的逐題判讀
3. 執行 `python build.py` 與 `python tools/verify.py`
